# How to run this exercise

## Aim of this exercise
This exercise demonstrates the Builder Design Pattern in Java. The main goal is to show how a complex object can be created step by step using a builder class instead of using a long list of constructor parameters. This makes the code more readable, easier to maintain, and helps create objects with optional fields in a clean way.

## Steps to run
Follow these steps in order:

1. Open a terminal in this folder:
   `cd "C:\Users\Somu\Desktop\CTS_DEEPSKILL\DeepSkilling\Week1\DesignPatterns\Exercise3_BuilderPattern"`

2. Compile the Java files:
   `javac *.java`

3. Run the test class:
   `java BuilderTest`

Expected output:
- Computer details will be displayed based on the values set in the builder.
