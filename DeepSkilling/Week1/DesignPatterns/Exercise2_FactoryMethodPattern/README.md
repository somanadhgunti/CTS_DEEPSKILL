# How to run this exercise

## Aim of this exercise
This exercise demonstrates the Factory Method Design Pattern in Java. The main goal is to show how object creation can be delegated to subclasses instead of hardcoding concrete classes in the client code. It helps in achieving loose coupling, better scalability, and easier extension when new document types need to be added.

## Steps to run
Follow these steps in order:

1. Open a terminal in this folder:
   `cd "C:\Users\Somu\Desktop\CTS_DEEPSKILL\DeepSkilling\Week1\DesignPatterns\Exercise2_FactoryMethodPattern"`

2. Compile the Java files:
   `javac *.java`

3. Run the test class:
   `java FactoryMethodTest`
